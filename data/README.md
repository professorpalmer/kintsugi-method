# data/

Licences and sources: `../LICENSES/DATA.md`. Names of arms and probes are the names of the project record; Appendix A
of the paper maps them to the names used in the text (for example V5bc-h32 = "KL-only winner", V5c = "KL-table B").

| Folder | Content | Read by |
|---|---|---|
| `appworld/` (first batch) | `<arm>-s<seed>.csv`: `task_id, success` (1 / 0) per task-run of AppWorld test_normal (168 tasks per seed). Arms: `v3ac`, `kship`, `pv3ac` = the shipped file (selection, fresh 102 + 103, fresh 104 + 105); `kfw` = its weights with f16 K/V on an 80 GB card; `bf16o`, `bf16f`, `pbf16` = BF16; `v5bc` / `pv5bc`, `v5t` / `pv5tc`, `v2body` / `pv2body` = the candidates; `q2kxlo`, `pnaive` = the naive UD-Q2_K_XL file in our engine; Inkling 2 Mini: `inkm` = M2 (ours), `raw` = the official weights, `q65` / `q262` = M2 with the 4-bit global cache, `ink` = Unsloth's setup. A file without a seed suffix (`v3ac`, `v5bc`, `v2body`) is seed 100 | `scripts/gg_stats.py`, `scripts/gg_seed_tn.py`, `scripts/make_figs.py` |
| `appworld/` (test_challenge, 417 tasks per seed) | `t3-pv3ac` = the shipped file (seeds 106, 107), `w2-pv3ac` = the shipped file (108, 109); `w2-pbf16` = BF16 (106-109); `w2-pv3acB` = the shipped file in BF16's setup; `t3-pv5bc` = KL-only winner; `w2-pv5tc` = KL-tools; `w2-pv5cc` = KL-table B; `w2-puni`, `w2-phawq` = the uniform and HAWQ-style baselines; `w2-psfd` = the band-only map; `w2-pw2cg3` = KL-table B with the down band restored; `w2-pv3ac0` = the shipped file with the two-stage head off; `w2-pv3ack` = the same with the 3-bit head and embedding (106 + 107 each); `w2-pv3acT`, `w2-pbf16T` = the shipped file and BF16 at temperature 0 (one greedy run each; seed 106 sent, not used) | `scripts/gg_seed.py`, `scripts/make_figs.py` |
| `appworld/` (Inkling 2 Mini, second batch) | test_normal seeds 108-111: `w2dm2` = M2, `w2da` = Unsloth UD-Q2_K_XL in our engine, `w2du` = the uniform map at the same bytes. test_challenge seeds 112 + 113: `w2im2` = M2, `w2iu` = the uniform map (one task less on seed 112), `w2-pfull` = the official weights (f16 K/V, 48 GB cards) | `scripts/gg_seed.py`, `scripts/make_figs.py` |
| `appworld/openings/` | per task-run of the 27B test_challenge arms: `task_id, first_word, first8_sha256_16` = the first word of the first reply and the first 16 hex characters of the SHA-256 of its first 8 words (joined by spaces). No reply text | `scripts/gg_seed.py` (parts 1a, 1b) |
| `margins/gc2/` | Inkling graded K/V margins: arms a (release), b (blanket q4_0), c (blanket q8_0), d (4-bit global cache) at 117k / 245k; `repeat/` = arm a repeated; `rig/` = arm a on a second machine (cross-check only) | `scripts/gc2_score.py` |
| `margins/gb2/` | the 44 recall items at 117k for the shipped file and the two baselines | `scripts/gb2_score.py` |
| `margins/w2d/` | Inkling graded recall of the second batch: `gm-<arm>-<depth>-<family>.jsonl`, arms `m2`, `a` (Unsloth's file), `u` (uniform map) | `scripts/w2d_margin.py` |
| `b1/out/`, `b1c/out/` | B1 and B1c margin records, one file per arm and document; `repeat/` = the run-floor repeat | `scripts/b1/b1_score.py`, `scripts/b1/b1c_score.py` |
| `w2c/out/` | the four flip maps of KL-table B on the B1 population (`W2Cg1`-`W2Cg4`: attn_qkv, attn_output, ffn_down 16-31, ffn_gate set back); `repeat/` = the run-floor repeat of the shipped file | `scripts/w2c_score.py` |
| `b1/population.jsonl.gz` | the B1 population (sha256 bc46d5dabc423d33b86c06c63c1f1260614eeb458c5ec2af523be4517aaba337) | `scripts/b1/b1_probe.py` |
| `freegen/` | free-generation records of the 24 needles at 245k: `bf16` (the reference: BF16, f16 K/V, no drafting), `shipped`, `kl-tools` (and its repeats: `-repeat`, `-mtp`, `-no-drafting`, `-vault9-first`), `kl-tools-qkv-back` and `kl-tools-ssmout-back` (KL-tools with one group at the shipped bits, all 24 items); `vault9-alone/` = one record per map for vault 9 asked alone | `scripts/freegen_summary.py` |
| `habits/return-turn-units.csv` | paper v1.3, the return turn of BFCL v3 multi_turn_miss_func (Qwen3.8-27B): one line per unit = `cell, history, entry, no_call, held_not_called, prompt_tokens, live_no_call`. `no_call` = miss rule 1 (the reply has no tool call); `held_not_called` = miss rule 2 (no call names a returned function); `live_no_call` = the first reply of the return turn in the live run that made the history. Histories: `HS` (made by the shipped file, 200 entries), `HT` (made by KL-tools-3, 198). Cells: `s0-shipped`, `s0-V5tf` (the 2 x 2; V5tf = KL-tools-3), `s0-shipped-HS-R1`, `-R2` (two repeats); `b-BF16`, `b-shipped`, `b-V5tf` (one 80 GB card, one setup; `b-BF16-HT` is not complete and is in no claim); `a6-*-nothink`, `s3-V5tf-nothink` (earlier thinking stripped), `s3-V5tf-xhigh`; `a3-*-va`, `-vb`, `-vc` (the three wordings); `a2-*-s2026120x` (sampling, three seed bases); `s1-V2body` (the second-fit file), `s1-SR`, `s1-SC`, `s2-k-*` (the shipped file with the common raises, the common cuts, one kind of them); `l1-*`, `l2-*`, `l3-*` (tensor copies between the shipped file and the second-fit file: Table H2 of the paper, names in its Appendix A). No prompt and no reply text | `scripts/v13_habits.py`, `scripts/make_figs.py` |
| `habits/inkling-firstcall-units.csv` | paper v1.3, the first call of an AppWorld task (Inkling 2 Mini): one line per task and seed = `arm, dataset, seed, task, no_code, cut`. `no_code` = the first reply has no code block; `cut` = the reply ended at the output cap of 1,024 tokens. Arms: `P1` = M2 (ours), `P2` = Unsloth UD-Q2_K_XL in our engine, `FP` = the official weights (run as Unsloth's UD-Q8_K_XL file, an exact copy of the release; a 48 GB card), on test_challenge; `R1` = M2, `C1` = M2 with f16 K/V, `C2` = M2 with no reasoning budget, `FPR` = the official weights, on test_normal seed 102. No prompt and no reply text | `scripts/v13_habits.py`, `scripts/make_figs.py` |
| `scores/` | result tables of the second batch as the lab scorers wrote them (machine names and private paths removed); the README of the repository says which paper numbers they hold | reading only |
| `bench/pycode.raw` | the copy corpus of the recall gate | `scripts/bench/` |
| `kl/<p1/p2>-<name>.csv` | per document: category, scored rows, KL sum, top-1 sum (p1 = build half, p2 = untouched half; `box-` = measured on the rented box with its own shipped-file reference) | `scripts/kl/kl_docs.py` |
